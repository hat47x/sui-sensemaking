# sui-sensemaking 利用ガイド

sui-sensemakingは、カードや島、関係線を使って情報を整理し、考えた過程を共有しやすくするWebアプリケーションです。このガイドは、初めて使う人や日常の運用を担当する人、情報の共有やAIの提案を安全に扱う方法を確認したい人向けの案内です。

このページから、目的に合う手順へ進んでください。すべてを一度に読む必要はありません。

このページで紹介する手順でも、SafeModeを既定で有効にすること、共有や書き出しの前に確認すること、未レビューの本文やAIの提案を人が確認することは変わりません。

起動後は「作業を開始」パネルで、新しい文書、サンプル、手元の`document.json`、レビューパックのいずれかを選びます。SafeModeがONであることを確認してから作業を始めてください。

## 安全に使う

sui-sensemakingでは、既定でAI機能と外部連携を無効にしています。最初に動作を確かめる際は、`SUI_LLM_PROVIDER=none`のまま起動してください。この状態なら、意図せず外部サービスへ接続することなく、保存や表示、共有前の確認などの基本操作を確かめられます。

共有、書き出し、AI提案、監査ログの連携を使う前には、次の文書を確認します。

## 困ったとき

画面が開かない、保存できない、AI提案が出ない、書き出した内容が想定と違うなどの問題がある場合は、まず [診断と障害調査](diagnostics.md) を確認してください。画面から再現確認をする場合は [受け入れ確認](acceptance_check.md) を使います。

問い合わせや共有用のメモを作るときは、秘密情報、APIキー、トークン、パスワード、未加工の顧客情報を含めないでください。どこまで残してよいか迷う場合は [データ取り扱い](data_handling.md) を先に確認します。

## 最小用語集

| 用語 | 意味 |
| --- | --- |
| Docker Compose | 複数のサービスをまとめて起動する仕組みです。sui-sensemakingでは、`web`、`api`、`db` をまとめて起動します。 |
| API | 画面とサーバー側の処理がやり取りするための入口です。通常は`/api/...`で呼び出します。 |
| セーフモード（SafeMode） | 未レビューの情報が混ざることや、外部サービスへの不用意な共有を防ぐための安全側の動作です。 |
| 大規模言語モデル（LLM） | 文章の生成や要約を行うAIモデルです。sui-sensemakingでは既定で無効です。 |
| プロバイダ | LLMの接続先の種類です。`none`、`local`、`large-scale` などがあります。 |
| 受け入れ確認 | 画面から実際に操作して、利用者の流れ全体を確認することです。 |
| 監査ログ | あとから確認できるように残す、操作の記録です。秘密情報を含めないことが前提です。 |
| 書き出し | アプリの中の情報を、ファイルとして取り出す操作です。共有する前に、秘密情報や不要なID情報が含まれていないかを確認します。 |
| 共有 | 他の人が閲覧できるようにする操作です。公開範囲、セーフモード（SafeMode）、読み取り専用の状態を確認してから使います。 |
| 公開範囲（visibility） | 公開する範囲の意図を示す分類です。SafeModeや読み取り専用による拒否の結果を、上書きするものではありません。 |
