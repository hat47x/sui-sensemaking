SUI Sensemaking / Architecture candidate / 2026-10-26

ツリーとKJキャンバスの独立UI・粘性付き配置

アウトライン／マインドマップで形成した論理的な親子関係を、自由配置のKJキャンバスへ背景の枝として投影する。人が形成した島・相対配置・違和感を保持し、AIと決定論的なレイアウトの協働を可逆に行う。

状態: 設計候補・未採用／未実装。 既存のDocumentV1、API、SafeMode、semantic kind、review/authority、履歴の意味を変更しない。本書の型名・パラメータ・ダイアグラムは検討用であり、公開契約とみなさない。要求と段階計画は 計画案、一次価値は ADR-0089 を参照する。

アウトラインとマインドマップは一つのTree/Forestを扱う別表示である。KJキャンバスは同じノードの参照先と座標・島を扱う独立したUI。マインドマップの整列は、生成直後のCanvas位置候補として一回利用してよいが、その後にCanvas座標を継続同期しない。

操作TreeMind-map位置Canvas位置・島背景枝
Canvasでカードを動かす維持維持明示範囲のみ更新現在位置で再描画
アウトラインで親を変更変更必要なら再整列維持新しい親子へ再接続
Mind-mapの自動整列維持変更維持維持
KJの島を作る・移す維持維持明示操作に従う親子の意味は維持

ツリー枝は 現行Edge の「関連」「対立」「因果」等の意味Relationへ複製せず、Treeの親子関係から導出する読み取り専用の描線とする。複数の親を一つのTreeで許すか、同じノードに複数Treeを許すかはPoCの観測事項。未分類カードは仮の表示ルートを正式な意味親にしない。

2. ツリーと島の食い違いを、描画の情報として残す

例: 部門別ツリー → 月末集中の島

Tree: 営業 ─ 受注確認
      経理 ─ 締め作業        → KJ島「月末集中」
      情報システム ─ バッチ

異なる祖先に属するカードが同じ島へ集まることは、元の分類軸を再検討する根拠にも、横断的な現象をそのまま表現する根拠にもなり得る。どちらの解釈も候補として扱う。

「異なる祖先から島へ集まる」という構造上の収束と、画面上の線が交わる幾何学上の交差を区別する。経路の最適化や束ねによって交差が減っても、出所構成を辿れるようにする。線の交差数を最小化することを唯一の目的にはしない。

背景枝の描画候補

  • 島／背景枝／既存の意味的なEdge／カード／選択オーバーレイの描画順を検討し、カード本文を優先する。背景枝と既存Edgeは識別できる表現にする。
  • ルート寄りの幹は太く、葉に向かう枝は細くする。ただし全体の不透明度を低くする。初期試験値の例は幹12px・中間7px・末端2〜3px、透明度6〜15%程度。実画面の可読性で調整し、仕様値として固定しない。
  • 共通幹の重複描画で濃くならないよう、一つの描画要素へ束ねるかレイヤー単位で透明度を制御する。ズーム別の太さ・密度・アンチエイリアスも評価する。
  • カード選択時は祖先経路を強調できる。表示の太さは意味上の重要度・Truth・採用状態ではなく、ツリー上の深さを示すだけである。
  • 枝の束ねや一時非表示は表示Projectionに限定し、位置・島・Tree・人間の注記を変更しない。

3. 代表カードと部分木の折り畳み

短いノードラベルは親の文脈を継承して意味を持つ。単語断片を大量のカードとして並べる代わりに、中間ノードを代表表示してよい。表示上の代表カードは元ノードの内容を置き換えず、対象のTree revision・部分木と子孫の参照を保持する。

代表の種類権威と保持
親のラベルそのもの元ノードへの表示参照
子孫から生成したAI要約提案または再生成可能な説明Projection。未解決・反証を省略して確定事実へしない
人が確認・編集した統合説明必要なら別のSynthesis候補。元の子孫と来歴へ戻る

アウトラインでの折り畳みとCanvasでの折り畳みは独立する。一つの部分木が複数島へ散らばる場合、代表表示を一箇所へ強制して島を壊さず、代表カードから複数島への参照・表示上の代理を使う候補を比較する。表示代理は同じノードの別意味成果物ではない。

4. 人の配置を保つ制約付き局所改善

AIがすべてのカードのXYを自由生成するより、AIは「どこを、どの意図で、どれほど変更するか」を候補として示し、決定論的なレイアウト処理が移動を解く構成を優先する。アルゴリズムの例:

入力: 現在の座標 P、Tree T、Island I、人手の明示注記 A、
      編集可能ID集合 S、固定ID集合 F、変化量制限 B
出力: 候補座標 P'（採用前は保存しない）

最小化:
  重なり・読みづらさ
  + 島内の形状変化
  + 利用者が示した位置関係の不満
  + 現在座標からの変化量
  + カード同士の相対位置の変化量

硬い制約:
  FとSの外側のカードは不変
  Treeの親子、カード本文、島の所属、Review、holdは不変
  P'の変化はBの範囲内（現実の距離定義はPoCで評価）

座標の粘性と相対位置の粘性を分ける。利用者が島を一括で大胆に移動した直後は、その移動後の座標を基準に内部の間隔・重なりだけを整える。枝の交錯が意味のある表現なら保持できる。

「この二つは近すぎる」「島全体の位置は維持」「この位置は固定」など具体的なコメントは候補制約へ変換できる。一方、「違和感がある」「納得感がある」「理由を言えない」は人間の認知上の信号として保持し、Truth、confidence、human review、意味上の承認へ自動変換しない。特に ADR-0090 の反スコアリング境界を維持する。

UI上の二つの制御軸

変更対象

選択カード／島／矩形領域／図全体。対象外は編集不能。固定した位置も編集不能。

変更量

保持 → 微調整 → 局所整理 → 明示的な大きな再配置。内部スコア係数だけでなく移動量の上限として扱う。

操作モードは微調整・共同整理・大胆な再構成の候補とする。スライダー最大でもハード制約を緩めない。人間の一括移動と、AIによる意味を変えない後処理を第一に試す。

5. 差分プレビュー、Undo/Redo、指定版からの部分復元

flowchart TD
  U["人の選択と指示"]
  B["現在Tree/Canvasの版・対象・固定を解決"]
  P["AIまたは決定論的手続きが操作候補を生成"]
  V{"範囲・版・安全条件に適合?"}
  D["差分プレビュー / 採否"]
  C["一つの編集単位で適用"]
  H["Undo/Redoと保存版の参照"]
  R["再指定・修正"]
  U --> B --> P --> V
  V -- はい --> D --> C --> H
  V -- いいえ --> R

Undo/Redoは同一セッションの操作単位とし、保存・再読込をまたいだ構造判断・人的な違和感の履歴の代用品にはしない。既存の Island shape設計 と同様、プレビュー中は保存せず、採用時に一度だけ確定する。

「ここ以外は前回版へ戻す」は、選択範囲・参照する旧Canvas版・現在Canvas版を解決し、許可された座標だけを旧版から戻す新たな差分操作とする。旧版にないカード、削除されたカード、Tree変更、島の所属、保留判断は別の変更として扱う。意味上の履歴を全体Undoで消去しない。対象が曖昧・消滅・現在版が古い場合は競合を提示する。

自然言語指示は直接Documentを更新せず、編集範囲・基準版・保持条件・対象IDを持つ操作候補へ変換する。AIへのContextは選択範囲と必要な関係を中心とし、SafeModeに従って外部へ送る。外部モデルが利用できなくても、人による配置、局所整列、Undo/Redoの経路を維持する。

6. 現行モデルとの適合と実装前の判断

既存資産利用可能な範囲と注意点
DocumentV1 / CardカードID・座標・本文・hold・critique。Tree identityの正式な永続契約は未実装
Island / Affiliation視覚的包含と横断的所属を区別する。ツリー上の親子に読み替えない
Edge意味的な線を保持する。Tree由来の背景枝を追加のEdgeとして保存しない
summaryHistory / critiqueHistory人が以前に残した見立てへ戻る。座標変更の操作履歴とは別
SUI Semantic ModelStructure / Synthesis / Review / Decisionを区別。将来概念と現行API/型のサポートレベルを混同しない
SEI・TEIとの連携Working Set・一般Tree/Graph/Layoutは将来の接続候補。SUIの初期PoCがそれらの完成を待つ必要はない

新しいTreeの永続化、Canvas版の保持形式、固定制約、注記の由来、代表テキストのリビジョン、異なるTreeの並存は未決である。実験用の独立fixtureから始め、既存DocumentV1変更の必要性、互換性、migration、SafeMode投影、API/TypeScript/Pydanticの整合を確認してから製品契約を決める。

7. 最小の検証と反証

負例・操作期待結果
人が作った島へ異なる親から3本の枝が入る意味のある交錯を残し、Treeと島を自動修正しない
マインドマップで再整列後、既存Canvasを開くCanvasの配置は保持される
「整えて」とAIが全体を動かそうとする範囲と粘性と上限で縮小／拒否し、未採用の候補として提示する
人が島を一括移動後、微調整を実行現在位置と内部形状を優先して余白を改善する
部分木の中に反証・heldがある代表説明から元情報へ戻れる。留保を断定へ変更しない
前版から選択対象以外を復元カード本文・Tree・島の意味は保持し、対象の位置だけ新しいUndo単位で適用
AI応答中に文書が変更されるstaleな候補の黙示適用を拒否する
AIなし／SafeMode ONで操作人の操作・履歴・基本的整列を維持し、未レビュー情報を外部送信しない
