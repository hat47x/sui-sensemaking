外部エージェント協調: 信頼境界とライフサイクル

区分: 設計ビュー・非正本 / 更新: 2026-08-06
正本は 02_Architecture/external_agent_collaboration_spec.html。本書はその図解ビューであり、内容が食い違う場合は正本を優先する。

この仕様が扱うのは 非信頼の外部エージェントへ「思考」を委任し、出力を提案としてのみ持ち帰る経路である。 外部エージェントの出力は常にデータとして扱い、指示として扱わない。

1. アクターと信頼境界（§2）

sequenceDiagram
  participant K as sui-sensemaking（自己ホスト・信頼）
  participant H as 利用者（人間・信頼・操作主体）
  participant A as 外部エージェント（非信頼）

  Note over K,H: 境界A: 依頼パッケージ
共有・書き出し境界
  K->>H: AgentTaskPackage v1（書き出し）
  H->>A: タスクシート投函（貼付・添付）

  rect rgba(146,64,0,0.08)
    Note over A: 思考の委任先
出力はデータ、指示ではない
    A-->>H: 応答（自由形式の思考結果）
  end

  Note over H,K: 境界B: 応答 / import信頼境界
  H->>K: AgentResponse v1（取り込み）
  K->>K: 検証・サニタイズ・提案化（未レビュー）

境界の性質はエージェント基盤ごとに異なる。M365などの組織契約に依存する経路は、本仕様の対象外である（§7 に個別の注意がある）。

2. AgentResponse のライフサイクル（§5）

stateDiagram-v2
  [*] --> drafted
  drafted --> exported: 書き出し・監査記録
  exported --> awaiting: 外部・不透明
（sui-sensemakingは追跡しない）
  awaiting --> imported: 取り込み
  imported --> under_review: under-review

  state under_review {
    [*] --> per_proposal
  }

  under_review --> adopted: 提案ごとに採否
  under_review --> rejected: 提案ごとに採否
  under_review --> held: 提案ごとに採否

  adopted --> applied: 適用（可逆）

  note right of awaiting
    sui-sensemaking が保持するのは
    drafted/exported と
    imported 以降のみ
  end note

  note right of applied
    ⌘Z で復帰可能
  end note

すべての採否は既存の決定ログへ記録される（merge系 = merge-decision-logs、CE4系 = context-audit operation=proposal/apply）。

3. 出力境界の既定値（§3.4）

項目既定
未レビュー本文既定除外（includeUnreviewedDrafts 明示時のみ含む）
出典参照（Card.meta.seq/source）既定OFF
主体メタ（起票者・作成者・最終更新者）別のゲートで同梱の可否が決まるまで含めない
